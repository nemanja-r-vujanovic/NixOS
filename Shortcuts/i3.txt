Super + Enter     = Open terminal

Shift + +         = Increase font (i3)
Shift + -         = Decrease font (i3)
Ctrl + +          = Increase font (alacritty)
Ctrl + -          = Decrease font (alacritty)

Super + D         = Run prompt
Super + 2         = New workspace

Alt + F4          = Close app
Super + Shift + Q = Close terminal
Ctrl + Q          = Close pcmanfm
